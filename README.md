# ArtisanConnect 🧵

AI-powered market linkage and smart cataloging platform for marginalized artisans, weavers, and micro-entrepreneurs.

Built for **Smart India Hackathon — PS ID 26090**.

## ✨ Features

- 🧑‍🎨 Artisan onboarding & profiles
- 🤖 AI-assisted product catalog generation
- 📸 Photo-based product listing
- 💰 AI-suggested pricing, titles, descriptions & tags
- 🛍️ Buyer marketplace with craft & region discovery
- 🌐 English / Hindi support
- 📶 Low-data / offline-friendly mode
- 📊 Artisan dashboard & market insights
- 🎯 Hackathon demo mode

## 🛠️ Tech Stack

**React.js · Tailwind CSS · Vite · Lucide React**

The prototype uses local React state, so no backend or API key is required.
