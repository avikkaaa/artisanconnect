# ArtisanConnect

Mobile-first React + Tailwind prototype for Smart India Hackathon PS ID 26090.

## Included demo flows

- Onboarding with voice/regional-language cues
- English/Hindi toggle
- Low-data/offline-friendly mode toggle
- Photo upload simulation + mock AI catalog generation
- AI-suggested title, category, description, price and tags
- Artisan dashboard with visual cards and market insights
- Buyer storefront with craft/region discovery and artisan stories
- Demo order interaction
- Local React state only — no backend required

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Notes

The product images use remote Unsplash image URLs for demo visuals. The AI cataloging is intentionally mocked so the prototype works without an API key or backend.
